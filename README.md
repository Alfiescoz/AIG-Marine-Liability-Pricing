# AIG Marine Liability Pricing Model

Experience-rated pricing model for marine third-party liability insurance, built in Excel as part of the AIG Actuarial Analyst job simulation on Forage (2026).

## Objective
Recommend a 2024 premium for a marine third-party liability policy using the client's historical claims experience.

## Method
- **Data cleaning:** reviewed and cleaned 100 historical marine liability claims
- **Adjustments:** projected claims to 2024 values for inflation, and applied the policy deductible and limits
- **Exploratory analysis:** used pivot tables and charts to identify trends by claim type, cause of loss and location
- **Pricing:** built an experience-rated model using loss frequency and severity, with a separate loading for large losses
- **Sensitivity testing:** tested how changes in claim severity affect the recommended premium

## Key Results
- Recommended 2024 premium: **$13.0m**
- A 6% increase in claim severity increases the premium by **5.8%**

## Tools
Microsoft Excel (data cleaning, pivot tables, charts, pricing calculations)
